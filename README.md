# Abhyas: Focused Haven

Create a modern, premium, and minimal website for "Abhyas Reading Library" located in Chandkheda, Ahmedabad. The design should feel luxurious, शांत (calm), and highly professional—similar to high-end coworking or study spaces.

🔷 Pages & Sections:

Home Page

Hero section with a full-width background image of the library (use high-quality images similar to those available on Google Maps / Justdial listings).

Tagline: "A Premium Space for Focused Learning"

CTA buttons: "Book a Seat" and "Admission Inquiry"

Quick highlights: AC Hall, Silent Environment, Individual Seating, WiFi, Power Backup

About Us

Short description about Abhyas Reading Library

Focus on discipline, productivity, and peaceful study environment

Gallery

Display all available images (grid + lightbox view)

Use real images from Google Maps/Justdial (cleaned and enhanced look)

Seat Availability (Dynamic Section)

Show total seats, occupied seats, and available seats

Example: Total Seats: 120 Occupied: 95 Available: 25

Include a "Check Availability" or "Reserve Now" button

Admission Inquiry Form

Fields: Name, Phone Number, Email, Preferred Timing (Morning/Afternoon/Night), Message

Submit button with modern UI

Show success message after submission

Pricing Plans

Monthly / Weekly plans

Highlight premium plan

Contact & Location

Embed Google Map for: Abhyas Reading Library, Chandkheda

Phone number and WhatsApp button

🔷 Design Style:

Dark + gold or white + soft grey premium theme

Smooth animations (fade, scroll)

Rounded cards, subtle shadows

Clean typography (Poppins / Inter)

Mobile responsive

🔷 Extra Features:

Sticky navbar

WhatsApp floating button

Testimonials section

FAQ section

🔷 Tech Stack:

Frontend: HTML, CSS, JavaScript (or React if needed)

Backend (optional): Firebase / Node.js for form + seat tracking

Use modern UI practices

🔷 Tone: Premium, calm, focused, distraction-free 🔷 Goal: Make the user feel: "This is the perfect place to study seriously."
